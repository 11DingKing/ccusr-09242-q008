# 水果深加工招商台账后端服务

记录合作主体、园区、项目、洽谈、立项、里程碑和投产后的产能兑现情况，为招商团队提供可追溯的业务接口。

## 产能提醒编排

在产能跟进模块之上提供统一的提醒窗口（`/api/v1/capacity/reminders`）：

- **生成与去重**：`POST /generate` 按项目承诺产能、实际达产率、上次联系时间计算下一次提醒；同一项目同时只保留一条未关闭提醒（数据库唯一约束兜底），重复触发幂等。
- **排期规则**：达产率 <50% 每 3 天、<80% 每 7 天、其余每 14 天；本地时间 09:00 触发，存储为 UTC 绝对时刻；节假日顺延规则由调用方在请求体中提供（`holidays` 放假日期、`weekend` 需顺延的星期，或注入自定义判定）。
- **到期推进**：`POST /mark-due` 把到达排期时刻的提醒置为「已到期」，纯数据库状态扫描，服务重启后启动补偿自动执行，可安全重复调用。
- **领取**：`POST /claim-for-assignee` 按责任人领取其名下全部到期提醒；`POST /{id}/claim` 单条领取。条件更新保证并发下只有一人领取成功（409 冲突）。
- **批量延期**：`POST /batch-postpone` 记录延期原因并按节假日顺延重新排期，已关闭条目自动跳过。
- **转交**：`POST /{id}/transfer` 保留完整处理链（`chain` 追加），已领取提醒转交后回到到期池；乐观守卫防止并发转交互相覆盖。
- **关闭**：`POST /{id}/close` 关闭后不再重复生成（除非关闭后出现新的未结跟进事项）；跟进事项标记「已解决/已关闭」时联动关闭其提醒。
- **依据查询**：`GET /{id}/basis` 返回生成依据快照（承诺产能、达产率、上次联系时间、顺延明细）与完整事件流、联系记录。

## 运行约定

服务端代码位于 `app` 目录，默认使用项目目录中的 SQLite 文件保存业务数据。环境变量可以覆盖数据库位置和接口前缀，临时配置不应提交到仓库。

## 测试

在项目根目录执行：

```bash
python3 -m unittest discover -s tests -v
```

## 编译检查

在项目根目录执行：

```bash
python3 -m compileall -q app tests
```

## 启动服务

准备依赖后可执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，根路径返回服务状态，接口文档位于 `/docs`。
