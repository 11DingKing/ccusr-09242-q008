# 水果深加工招商台账后端服务

记录合作主体、园区、项目、洽谈、立项、里程碑和投产后的产能兑现情况，为招商团队提供可追溯的业务接口。

## 产能跟进提醒编排

在产能跟进模块上提供统一的提醒窗口：

- **生成规则**：按项目承诺产能、最新达产率（折算缺口）和上次联系时间计算下一次提醒。缺口 ≥50% 每 3 天、≥30% 每 7 天、≥15% 每 14 天，其余每 30 天；从未联系过的事项立即进入提醒窗口。
- **节假日顺延**：由调用方在生成时提供节假日列表与是否跳过周末，规则随提醒留存，处理后自动续排下一次时沿用。
- **去重与关闭**：每个跟进事项至多一条未结提醒（数据库部分唯一索引保证），重复/并发生成幂等跳过；跟进事项关闭或解决后未结提醒自动取消且不再生成。
- **日常操作**：按责任人领取、批量延期（原因必填）、转交（事件表保留完整处理链，乐观锁防并发）、处理完成自动编排下一次。
- **到期恢复**：服务启动时自动扫描到期提醒并置为待处理，重启不丢提醒窗口；也可通过 `POST /capacity/reminders/process-due` 手动或定时补跑。

接口位于 `/api/v1/capacity/reminders` 前缀下，详见 `/docs`。

## 运行约定

服务端代码位于 `app` 目录，默认使用项目目录中的 SQLite 文件保存业务数据。环境变量可以覆盖数据库位置和接口前缀，临时配置不应提交到仓库。

## 测试

在项目根目录执行：

```bash
python3 -m unittest discover -s tests -v
```

## 编译检查

在项目根目录执行：

```bash
python3 -m compileall -q app tests
```

## 启动服务

准备依赖后可执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，根路径返回服务状态，接口文档位于 `/docs`。
